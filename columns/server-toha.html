そもそもサーバーって何？学習塾の経営者向けにやさしく解説

ホームページのデータを預かり、届ける係。
公開の仕組みと、情報を守る考え方をやさしく解説します。

サーバーとは、ホームページのデータを預かり、「見せてください」と頼まれたら渡す係のことです。

たとえるなら、図書館の受付です。「この本をください」と言われたら、「はい、どうぞ」と渡す。ここでは、塾の紹介ページのデータを届ける役割に絞って考えてみましょう。

前回の記事では、無料のサーバーで運用している塾のホームページを紹介しました。今回は、そもそもサーバーとは何か、無料で使うときは何を確認するかを説明します。

ホームページは「そこにある」ものではありません

ホームページは、マンションのようにどこかに建っているものではありません。見るたびに、データを取りに行って、手元で開いています。

スマホで塾のホームページを開くとき、裏側では次のことが起きています。

  1. 保護者の方が、ホームページのアドレスを開く
  2. スマホがサーバーに「このページの情報をください」と頼む
  3. サーバーが「はい、どうぞ」とデータを渡す
  4. スマホがそのデータを読み取り、画面に表示する

このやりとりが、ページを開くたびに一瞬で行われています。

渡されるのは、ブラウザが読める3つの言語です

サーバーが渡すデータは、ブラウザが読み取れる言語で書かれています。ブラウザとは、SafariやGoogle Chromeのような、ホームページを見るためのアプリのことです。

使われる言語は、基本的に次の3つです。

  • HTML：文章や見出し、画像など、ページの中身
  • CSS：色や文字の大きさ、配置など、見た目
  • JavaScript：メニューの開閉など、動き

SafariでもGoogle Chromeでも、読んでいる言語は基本的に同じです。だから、どのスマホやパソコンで開いても、ほぼ同じようにホームページが表示されます。

サーバーが必要なのは、24時間応対するためです

「このページをください」という依頼は、いつ来るか分かりません。昼間とはかぎらず、深夜にも来ます。

これに人間が応対するのは無理です。そこで、データをサーバーに置いておき、サーバーに自動で応答してもらいます。

つまりサーバーの仕事は2つです。データを保管すること。そして、24時間いつでも渡せるようにしておくことです。

ホームページの公開方法は、大きく3つあります

公開方法どういうものか費用
自分で機器を用意する常に動かす機器や回線を自分で管理する機器代・電気代・回線代など
レンタルサーバー事業者が用意した場所を借りるプランや契約期間による
公開サービスの無料枠ホームページのデータを預けて公開する条件に合う範囲は無料

自分で機器を用意すると、停電や故障、通信の設定なども自分で対応します。塾の運営と並行して管理するには負担が大きいため、事業者のサービスを使うのが一般的です。

レンタルサーバーには、ロリポップ！やエックスサーバーなどがあります。料金は契約期間や機能で変わるので、更新時の金額も確認します。

無料で公開できるサービスの一例が、GitHub Pages（ギットハブ・ページズ）です。ホームページのデータを預けて公開できます。無料プランで使う場合、元のファイルも誰でも見られる場所に置くため、パスワードや問い合わせ内容などを混ぜないことが大切です（GitHub公式の説明）。

なお、レンタルサーバーと公開サービスは、どちらも事業者の設備を利用する方法です。違うのは、利用者が管理する範囲や使える機能です。

無料かどうかより、使える条件と管理方法を確かめます

GitHubは開発者向けのサービスで、Microsoftは2018年に買収合意を発表しています（Microsoftの発表）。ただし、提供元が大手だからといって、どんな使い方でも安全とは限りません。

GitHub Pagesにも、オンラインビジネスや商取引を主目的とするサイトなどの利用制限があります。学習塾のサイトでも、内容や目的が条件に合うかを確かめ、必要なら別のサービスを選びます（公式の利用条件）。

情報漏えいを防ぐために、大切にしている2つのこと

公開する場所に、見られて困る情報を置かないこと。そして、管理するための入口を守ること。 塾HPナビでは、この2つを基本に考えています。

1. 公開するホームページと、問い合わせ情報を分ける

コース案内、料金、アクセス、講師紹介は、保護者に見ていただくための情報です。一方で、お問い合わせの名前や連絡先は、誰でも見られる場所に置いてはいけません。

新規制作では、原則としてGoogleフォームへの案内を用意します。ホームページでは塾の情報を紹介し、問い合わせの受付と回答の保管はGoogleフォームで行います。サイトの公開用データに、問い合わせ内容を保存しない構成です。

2. 管理アカウントと、情報を見られる範囲を守る

塾HPナビのホームページは、PHP・WordPressを使わず、HTML・CSS・JavaScriptで制作します。ホームページ側にWordPressのログイン画面を設けず、管理する仕組みを少なくします。

それでも、公開サービスやGoogleの管理アカウントは守る必要があります。二段階認証を使い、担当者だけが回答を見られるようにし、不要な共有を解除します。Googleフォームの「回答の概要」を回答者に公開しないことも確認します（Googleフォームの公式ヘルプ）。

アクセス分析を導入する場合も、Googleなど、運営元と安全対策が確認できる大手のサービスを基本に選びます。氏名やメールアドレス、問い合わせ内容を分析データに含めないよう設定します。

サービスの設備や仕組みの保護は提供元が担います。一方、何を集めるか、誰に見せるか、アカウントをどう守るかは、利用する側でも管理します。Googleを使えば事故が起きない、すべての責任が提供元に移る、ということではありません。

もしホームページを書き換えられてしまったら

小さな塾でも、偽の連絡先や不正なリンクに書き換えられると、保護者に被害が及ぶおそれがあります。気づいたら速やかに公開を止めるなどして、影響を広げない対応が必要です。

元のデータを戻すだけでなく、アカウントや設定を確認し、原因を取り除いてから再公開します。そのためにも、データの控えと、困ったときの連絡先を用意しておきます。

まとめ

  • サーバーは、データを預かって渡す「図書館の受付」のような役割です
  • 人の代わりに、いつでもページのデータを届けられるようにします
  • 無料で公開する方法もありますが、使える条件を確認して選びます
  • 公開する情報と問い合わせ情報を分け、管理アカウントと閲覧権限を守ります

サーバーの役割が分かると、「サーバー管理費」という請求の見え方も変わるはずです。何を任せている費用なのか、一度確認してみてください。
