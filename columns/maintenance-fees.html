学習塾のホームページは、月々のランニングコスト0円で運用できます。 毎月のサーバー代も、運用保守費もいりません。かかるのは、年に約1,500円のドメイン代だけです。

ここでお話しするのは、塾の紹介、コース・料金の案内、お問い合わせの受付をするホームページです。実際に、次の3つのホームページは、毎月のサーバー代も運用保守費も払わずに公開しています。

  • 大阪公立大学専門 桜灯塾
  • 会員制難関受験専門塾 elio
  • Kokuban BASE

サーバーは、0円のものを選べます

写真や書類を無料で預けられるGoogleドライブのように、ホームページを置くサーバーにも無料のものがあります。その代表が、GitHub Pages（ギットハブ・ページズ）です。

ホームページのデータ（コード）をGitHubに置いておくと、GitHub Pagesがそれをそのままインターネット上に公開してくれます。自分でサーバーを借りる契約をしなくても、クラウド上のサーバーとして使えるということです。

いまご覧のこの塾HPナビのホームページも、GitHub Pagesで公開しています。

なお、GitHub Pagesには利用条件があり、ネットショップや決済など、サイト上での取引を主な目的とするホームページは対象外です（公式の利用条件）。塾HPナビでは、塾の紹介とお問い合わせの受付を中心にした構成で制作しています。

運用保守費も、0円でかまいません

毎月の保守費は、多くの場合「仕組みを更新し続ける作業」や「不正アクセスへの備え」のためのお金です。この作り方のホームページには、そのどちらも必要ありません。

  • サーバーの管理はGitHubが行います。 自分たちで機器やソフトを更新する作業がありません。
  • ホームページの中に個人情報を保存しません。 会員のログイン画面も、管理画面も、データベースもないので、盗まれて困るものが置かれていません。
  • 更新し続ける仕組みを使っていません。 WordPressのように、放っておくと古くなる仕組みがないため、定期的な更新作業がいりません。

お問い合わせフォームから届いた内容は、ホームページの中ではなくGoogleのスプレッドシートに記録され、通知メールで届きます。保護者の連絡先を守るために、そのGoogleアカウントには2段階認証を設定しておきましょう。これにも費用はかかりません。

文章や料金を変えたいときは、その部分だけを直して公開し直します。毎月の契約にしなくても、必要なときにその都度対応すれば足ります。

ただし、ドメイン代だけは年間約1,500円かかります

ドメインとは「〇〇juku.com」のような、ホームページの住所です。これだけは無料にならず、使い続けるために年1回の更新料がかかります。

塾HPナビでは年間約1,500円を目安にご案内しています。月に換算すると約125円です。ドメインの種類や契約先によって金額は変わります。

年払いなので、毎月の請求はありません。更新を忘れるとホームページが表示されなくなるため、自動更新にしておくと安心です。

あとは、最初に制作費を払えば完了です

塾HPナビの制作費は、一括99,000円（税込）です。公開後に毎月いただく費用はありません。

わたしは現役塾講師としてお話を伺い、その塾の強みが伝わる構成とデザインを考えます。授業や教室運営で忙しい先生は、作る作業をまるごとお任せいただけます。

月1万円の保守費は、5年で60万円になります

毎月の金額は小さく見えても、払い続けると大きな費用になります。

月額1年間5年間
5,000円6万円30万円
1万円12万円60万円
3万円36万円180万円

お知らせの更新や、困ったときの対応まで任せているなら、その支払いには意味があります。一方、ほとんど何も頼んでいないのに「管理費」として払い続けているなら、何のための費用かを一度確認してみてください。

毎月の保守契約が必要なのは、ログインや決済があるホームページです

次のようなホームページでは、専門の人に継続して見てもらう意味があります。

  • 会員がログインして、個人情報や支払いを管理する
  • 予約や決済など、複数の仕組みを組み合わせている
  • WordPressなど、定期的な更新が必要な仕組みを使っている
  • 毎月たくさんの更新を代行してもらいたい

大切なのは、自分の塾に必要な作業と、支払っている費用が合っているかです。

よくある質問

無料のサーバーでも、お問い合わせフォームは作れますか？

作れます。お問い合わせを一覧に記録し、塾へ通知メールを送り、保護者へ受付完了メールを自動で返すところまで対応できます。

文章や料金表を変えたいときは？

自分で編集する方法も、必要なときだけ制作者に頼む方法もあります。依頼の方法と費用は、制作時に確認しておくと安心です。

GitHub Pagesが有料になったり、使えなくなったりしたら？

料金や利用条件が変わる可能性はあります。ホームページのデータは手元に残るので、その場合は別の公開先へ移せます。

いまの保守契約は、すぐに解約してよいですか？

先に3点を確認してください。ドメインを誰が管理しているか、ホームページのデータを受け取れるか、解約の条件（契約期間、申し出の期限、メールへの影響）は何か、です。新しいホームページが動くことを確かめてから、古い契約を終えます。

まとめ：かかるのは、ドメイン代と最初の制作費だけです

  • 毎月の運用保守費：いりません
  • 毎月のサーバー代：いりません
  • ドメイン代：年間約1,500円（月あたり約125円）
  • 制作費：最初に一度払えば完了

ホームページには必ず毎月の費用がかかる、というわけではありません。制作や公開後の費用についてのご相談は完全無料です。いまの塾の状況を聞かせていただくところから始めます。
